# Changelog

## Unreleased (releases are named by date and patch, e.g. 2026-10-28-patch1)

- Niri: `le-dock`, a macOS-style dock (GTK4 + layer-shell): running apps appear (and unpinned ones vanish when
  closed), dots under running/focused apps, bounce on launch and urgent, hover zoom, click to focus/cycle,
  middle click for a new window, right click menu (windows, pin, quit). Falls back to the waybar dock when
  GTK4/gtk4-layer-shell is missing (`niri-bars` / settings: Dock > look).
- Niri bars: size is set per bar (top and dock), the dock can be hidden alone (`Super+Ctrl+B`), the top bar
  too (`Super+Alt+B`), and the top bar can be docked flush to the top edge with square corners
  (Settings > Top bar > style).
- Niri menus use icons (`niri-menu`); the wallpaper picker shows thumbnails and the theme picker colour
  swatches (`niri-thumbs`). `niri-theme` also writes a matching `fuzzel.ini`.

- Niri settings menu (`Super+Shift+D` or the gear on the top bar): theme and auto theme, wallpaper,
  bar and dock size, display, window gaps, rounded corners, terminal opacity, bars, key list.
- Niri bar and dock size: `compact`, `small`, `normal`, `large` (`niri-bars size ...`). The bar files stay
  as installed; scaled copies are generated into `~/.config/waybar/gen/`.
- Niri display settings (`niri-display`): resolution/refresh, scale, rotation, on/off per screen, with a
  12 second confirm-or-revert, saved to `display.kdl` so they persist.
- Niri auto theme: changing the wallpaper with `niri-wall` rebuilds the palette from the picture and
  recolors niri, waybar, mako and kitty (open terminals too). The switch is shared with dwm.
- `niri-theme` now also writes the kitty colors (it only touched niri, waybar and mako before), and
  `niri-theme from-image <file>` builds a theme from a picture.
- Fixed: a fresh niri-only install had no wallpapers and no kitty theme include; `niri-wall` no longer
  flashes when switching (the new `swaybg` starts before the old one stops); the installer's Restart entry
  also restarts the niri bars; waybar/kitty reload signals also reach NixOS' `.waybar-wrapped`.
- The installer keeps `include dwm-theme.conf` as the last line of `kitty.conf`, so a theme set earlier with
  kitty's own theme chooser (`current-theme.conf`) can no longer override the wallpaper colors.
- NixOS module puts `~/.local/bin` on the PATH, so `dwm-wall`, `dwm-theme` etc. work in a shell.
- Fixed on NixOS: open kitty windows now recolor when the theme changes (NixOS runs kitty as `.kitty-wrapped`,
  so the reload signal never reached it); same for Thunar and waybar. Auto theme now reports why it failed
  (notification + `~/.config/dwm-theme/auto-theme.log`) instead of failing silently.
- Fixed the uptime item on the second bar ("invalid option -p" on NixOS): it now reads `/proc/uptime`
  through the new `dwm-uptime`.
- Installer updates detect the distro: NixOS runs `nix flake update le-dwm` + `nixos-rebuild switch`,
  Arch-based systems run `pacman -Syu`, anything else updates only the dotfiles. Asks first on a terminal;
  `SKIP_SYSTEM_UPDATE=1` skips it. The NixOS module looks up Thunar by its new top-level name.
- NixOS support: `nixos/le-dwm.nix` (also `nixosModules.default` in `flake.nix`) installs the programs,
  fonts and a `le-dwm` login session; `./install.sh` detects NixOS, skips pacman/sudo steps and builds
  dwm inside a nix dev shell (`le-devrun`, `nix/devshell/flake.nix`) so the libraries are not garbage
  collected. The module was evaluated against current nixpkgs, but a full build was not run.
- The dock and app lookup now read `XDG_DATA_DIRS` (plus NixOS, Flatpak and per-user locations), so
  apps and icons are found outside `/usr/share`.
- Niri: macOS-style dock - a floating glass pill with real app icons (read from each app's .desktop
  file), a divider and the launcher, hover highlight and lift. Gaps are now 14 px and window corners
  14 px, so windows no longer touch the bars.
- Niri: `Super+Shift+/` (or `niri-keys`) now lists every key from your real `config.kdl` in a
  searchable menu, instead of niri's partial overlay. It updates itself when you add binds.
- Installer now runs `sudo pacman -Syu` before installing packages, so a stale database no longer
  causes 404s (e.g. when installing waybar for niri).
- Fixed a false "dwm did NOT build" error: `dwm -v` exits with status 1, which `pipefail` treated as
  a failed build even though `make install` succeeded.
- Niri (Wayland) support: `niri/config.kdl` mirrors the dwm look - 8 px gaps, a 2 px focus ring,
  rounded windows and the same Super key bindings.
- Floating top bar (waybar): workspace icons, focused window title, tray, network, Bluetooth, volume,
  backlight, battery and clock in the dwm style.
- Compact bottom application dock generated by `niri-dock`; click the launcher in the middle to run,
  pin or unpin apps (right-click an icon to unpin), pinned apps in `~/.config/niri/dock-apps`.
- `niri-theme` generates niri colors, waybar CSS and the mako config from the same `themes/*.theme`
  files as dwm; `niri-wall` handles wallpapers through swaybg from `~/Pictures/wallpapers`.
- `niri-bars` starts/restarts/toggles both bars (`Super+B` hides them, `Super+Shift+B` opens a menu),
  `niri-keys` shows the key sheet.
- Installer menu now has Install dwm / Install Niri / Update dwm / Update Niri / Restart / Quit, with
  `--install-dwm`, `--install-niri`, `--update-dwm` and `--update-niri` flags. The niri install adds
  niri, waybar, swaybg, mako, grim, slurp and wl-clipboard.
- dwm 6.x config with Nerd Font tag icons, kitty terminal, Thunar, screenshots, media keys.
- Top bar status (cat, online/offline, Bluetooth, volume, brightness, battery, clock) and a
  polybar bottom bar; both translucent through picom (default 75%).
- Theme switcher (`dwm-theme`, Super+Shift+T): Nord, Gruvbox, Catppuccin Mocha/Latte,
  Tokyo Night, Dracula for dwm, polybar, GTK/Thunar, kitty and dmenu.
- Wallpaper manager (`dwm-wall`, Super+Shift+W / Super+Ctrl+W).
- Quit confirmation (Super+Shift+Q) and a themed power menu for the top-bar power button.
- Window gaps (8px), icon-only power button (`patch-dwm.py`).
- picom: kitty transparency, translucent bars, open/close and tiling-move animations.
- Installer keeps an existing `~/dwm/config.h`.
- 11 more themes: Rose Pine (+ Dawn), Everforest, Solarized Dark, One Dark, Kanagawa, Ayu Mirage, GitHub Dark,
  Catppuccin Frappe/Macchiato, Gruvbox Light.
- Theme from wallpaper: `dwm-theme from-image` (images and videos), `dwm-wall auto on|off`; unchanged colors
  no longer trigger a dwm rebuild.
- `dwm-live`: live wallpaper manager (xwinwrap + mpv) with theme-from-video and login restore via `dwm-wall restore`.
- `dwm-live`: key Super+Ctrl+Shift+W and a middle-click on the bottom bar's wallpaper button open the live-wallpaper picker.
- Wallpaper picker (Super+Shift+W): centered rofi window with cached previews of pictures and live wallpapers; choosing applies it and recolors the theme.
- Bottom bar shows resources as used/total (CPU threads `1.6/8`, RAM and disk in GB) instead of percentages.
- Empty-workspace animation: a ripple (`dwm-flash`) plays when you switch to a workspace with no windows.
  Opt out with `touch ~/.config/dwm-theme/no-flash`.
- picom animations a little slower (open/move 0.28s, close 0.22s).
- `dwm-theme` rebuilds dwm when `dwm.c` or `config.h` are newer than the installed binary, even if the colors did not change.
- Bar styles (`dwm-bar`, Super+Shift+B): one or two bars, top or bottom, stacked, floating or edge to edge,
  full or compact second bar, four icon sets, tag styles, running cat and CPU/RAM/disk on or off, presets.
- Floating bars and rounded windows (picom `corner-radius`); default style is now two floating bars with
  8 px corners. `dwm-bar preset classic` restores the old edge-to-edge look.
- polybar bar renamed `main`; picom.conf, polybar config and the status icons are generated by `dwm-bar`.
- patch-dwm: bar layout read from `barcfg.h`, systray follows the floating bar, gaps follow the bar margin.
- Session safety: `start-dwm` logs to `~/.local/state/dwm/session.log`, shows an error window instead of a grey screen
  when dwm is missing or crashes, and starts in safe mode after a crash. `dwm-doctor` collects a diagnosis.
- `install.sh` stops (and shows the build log) if dwm fails to build, before touching the login session.
- Clickable status items: Wi-Fi (network editor), Bluetooth (Blueman), volume (pavucontrol), battery (power profile
  menu with the active profile shown). New packages: nm-connection-editor, pavucontrol, blueman, bluez-utils,
  power-profiles-daemon.
- Settings menu (`dwm-settings`, Super+Shift+D, gear on the bottom bar): display, theme, bar, wallpaper,
  gaps, rounded corners, bar opacity, animations, terminal opacity and session tools in one rofi/dmenu menu.
- Display settings (`dwm-display`): per-monitor resolution/refresh, primary, rotation, extend/mirror/single,
  and a saved layout (`~/.config/dwm-theme/display.sh`) applied by `start-dwm` at login.
- Fixed the build failure when `config.h` has the `ClkStatusSegment` binding: `patch-dwm.py` now adds the
  enum, prototypes and click dispatch to `dwm.c` (and repairs older status-click patches).
- Fixed the dead `xrandr` line after `exec` in `~/.xinitrc`; display settings now go through `start-dwm`.
- Bundled wallpaper (`wallpapers/coastline.jpg`), installed by `install.sh` and available with
  `dwm-wall default` / "Bundled wallpaper" in the settings menu.
