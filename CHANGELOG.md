# Changelog

## Unreleased (releases are named by date and patch, e.g. 2026-10-28-patch1)

- dwm 6.x config with Nerd Font tag icons, kitty terminal, Thunar, screenshots, media keys.
- Top bar status (cat, online/offline, Bluetooth, volume, brightness, battery, clock) and a
  polybar bottom bar; both translucent through picom (default 75%).
- Theme switcher (`dwm-theme`, Super+Shift+T): Nord, Gruvbox, Catppuccin Mocha/Latte,
  Tokyo Night, Dracula for dwm, polybar, GTK/Thunar, kitty and dmenu.
- Wallpaper manager (`dwm-wall`, Super+Shift+W / Super+Ctrl+W).
- Quit confirmation (Super+Shift+Q) and a themed power menu for the top-bar power button.
- Window gaps (8px), icon-only power button (`patch-dwm.py`).
- picom: kitty transparency, translucent bars, open/close and tiling-move animations.
- Installer keeps an existing `~/dwm/config.h`.
- 11 more themes: Rose Pine (+ Dawn), Everforest, Solarized Dark, One Dark, Kanagawa, Ayu Mirage, GitHub Dark,
  Catppuccin Frappe/Macchiato, Gruvbox Light.
- Theme from wallpaper: `dwm-theme from-image` (images and videos), `dwm-wall auto on|off`; unchanged colors
  no longer trigger a dwm rebuild.
- `dwm-live`: live wallpaper manager (xwinwrap + mpv) with theme-from-video and login restore via `dwm-wall restore`.
- `dwm-live`: key Super+Ctrl+Shift+W and a middle-click on the bottom bar's wallpaper button open the live-wallpaper picker.
- Wallpaper picker (Super+Shift+W): centered rofi window with cached previews of pictures and live wallpapers; choosing applies it and recolors the theme.
- Bottom bar shows resources as used/total (CPU threads `1.6/8`, RAM and disk in GB) instead of percentages.
- Empty-workspace animation: a ripple (`dwm-flash`) plays when you switch to a workspace with no windows.
  Opt out with `touch ~/.config/dwm-theme/no-flash`.
- picom animations a little slower (open/move 0.28s, close 0.22s).
- `dwm-theme` rebuilds dwm when `dwm.c` or `config.h` are newer than the installed binary, even if the colors did not change.
- Bar styles (`dwm-bar`, Super+Shift+B): one or two bars, top or bottom, stacked, floating or edge to edge,
  full or compact second bar, four icon sets, tag styles, running cat and CPU/RAM/disk on or off, presets.
- Floating bars and rounded windows (picom `corner-radius`); default style is now two floating bars with
  8 px corners. `dwm-bar preset classic` restores the old edge-to-edge look.
- polybar bar renamed `main`; picom.conf, polybar config and the status icons are generated by `dwm-bar`.
- patch-dwm: bar layout read from `barcfg.h`, systray follows the floating bar, gaps follow the bar margin.
- Session safety: `start-dwm` logs to `~/.local/state/dwm/session.log`, shows an error window instead of a grey screen
  when dwm is missing or crashes, and starts in safe mode after a crash. `dwm-doctor` collects a diagnosis.
- `install.sh` stops (and shows the build log) if dwm fails to build, before touching the login session.
- Clickable status items: Wi-Fi (network editor), Bluetooth (Blueman), volume (pavucontrol), battery (power profile
  menu with the active profile shown). New packages: nm-connection-editor, pavucontrol, blueman, bluez-utils,
  power-profiles-daemon.
- Settings menu (`dwm-settings`, Super+Shift+D, gear on the bottom bar): display, theme, bar, wallpaper,
  gaps, rounded corners, bar opacity, animations, terminal opacity and session tools in one rofi/dmenu menu.
- Display settings (`dwm-display`): per-monitor resolution/refresh, primary, rotation, extend/mirror/single,
  and a saved layout (`~/.config/dwm-theme/display.sh`) applied by `start-dwm` at login.
- Fixed the build failure when `config.h` has the `ClkStatusSegment` binding: `patch-dwm.py` now adds the
  enum, prototypes and click dispatch to `dwm.c` (and repairs older status-click patches).
- Fixed the dead `xrandr` line after `exec` in `~/.xinitrc`; display settings now go through `start-dwm`.
- Bundled wallpaper (`wallpapers/coastline.jpg`), installed by `install.sh` and available with
  `dwm-wall default` / "Bundled wallpaper" in the settings menu.
