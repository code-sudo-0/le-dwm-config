# le-dwm-config

A complete, themeable **dwm** desktop for CachyOS / Arch (X11): floating bars, rounded windows, smooth
animations, one-key themes that follow your wallpaper (including live wallpapers), and a Thunar that
matches everything else. One installer sets it all up.

## Highlights

- **Bar styles** (`Super+Shift+B`): one or two bars, top or bottom, floating or edge to edge, compact,
  four icon sets, eight presets
- **Themes** (`Super+Shift+T`): 17 palettes that recolor dwm, polybar, kitty, dmenu and GTK/Thunar at once
- **Wallpapers** (`Super+Shift+W`): a centered preview grid of pictures and live wallpapers; picking one
  recolors the whole desktop from it
- **Rounded windows, 8 px gaps, translucent bars, Hyprland-style animations** through picom,
  plus a ripple when you switch to an empty workspace
- **Status** with real numbers: CPU threads busy/total, RAM and disk used/total, Bluetooth, battery
- **Clickable status** on the top bar: WiFi opens the network manager, Bluetooth opens Blueman,
  volume opens pavucontrol, the battery opens the performance profile menu (Performance / Balanced / Power Saver)
- **Floating top and bottom bars** with the windows kept clear of both (default style)
- **Installer menu** with Install / Update / Restart / Quit; Update pulls the repo and re-applies it
- Themed power menu, quit confirmation, keybind cheat sheet (`Super+Shift+/`)

## What's in here

| File | Purpose |
| --- | --- |
| `config.h` | dwm 6.5 config (keys, fonts, layout) |
| `colors.h` | default colors; regenerated by `dwm-theme` |
| `dwmstatus.sh` | top-bar status: cat, resources, online/offline, volume, brightness, battery, clock |
| `dwm-statusclick`, `dwm-perf` | status-item clicks; performance profile menu (battery) |
| `polybar/config.ini.in` | second bar template: CPU, RAM, disk, temp, uptime, network speed, buttons |
| `dwm-bar` | bar styles, floating bars, icon sets, rounded windows |
| `dwm-theme` + `themes/` | theme switcher and palettes; `dwm-palette` builds a theme from a picture |
| `dwm-wall`, `dwm-live` | wallpaper picker, live wallpapers |
| `dwm-cpu`, `dwm-flash.c` | CPU readout; empty-workspace ripple (built by the installer) |
| `dwm-keys` | keybind cheat sheet |
| `start-dwm`, `dwm-quit`, `dwm-power-menu` | session launcher, quit prompt, power menu |
| `patch-dwm.sh`, `patch-dwm.py` | small checked patches to `dwm.c` / `config.h` |
| `install.sh` | installer / updater menu |

## Install

```
git clone https://github.com/code-sudo-0/le-dwm-config.git
cd le-dwm-config
./install.sh
```

The installer opens a menu:

1. **Install** - packages, dwm, bars, themes, session entry (first setup or a repair)
2. **Update** - `git pull` and re-apply everything, keeping your own `config.h`
3. **Restart** - restart dwm; your windows stay open
4. **Quit**

After Install or Update it returns to the same menu. **Run Update every day or so** to keep the
dotfiles current. A wallpaper can still be passed directly: `./install.sh ~/Pictures/wallpaper.jpg`.

Then log out and pick the **dwm** session, or run `startx` from a TTY.
If the packaged `dwm` is installed it can shadow the build: `sudo pacman -R dwm`.

## Themes

`Super+Shift+T` (or click the brush in the bottom bar) opens a list. One choice recolors
dwm, both bars, dmenu, kitty, and GTK apps including Thunar and its icons.
Included (17): Nord, Gruvbox Dark/Light, Catppuccin Mocha/Macchiato/Frappe/Latte (light), Tokyo Night, Dracula,
Rose Pine, Rose Pine Dawn (light), Everforest Dark, Solarized Dark, One Dark, Kanagawa, Ayu Mirage, GitHub Dark.
The "Wallpaper (auto)" theme appears in the list once you have made one from a picture (see below).

From a terminal: `dwm-theme list`, `dwm-theme set nord`, `dwm-theme current`.

Make your own by copying a file in `~/.config/dwm-theme/themes/`, changing the colors, and
picking it from the list. A theme is just a dozen color variables.

**Heads-up:** dwm has its colors compiled in, so changing theme rebuilds dwm and restarts it.
Your programs stay open, but they all reappear on the tag you are viewing. Everything else
(bottom bar, kitty, GTK) updates live; reopen Thunar to see its new look.

## Wallpapers

Put pictures in `~/Pictures/wallpapers` and live wallpapers (videos) in `~/Videos/Live wallpapers`.

- `Super+Shift+W`: a window in the middle of the screen with a preview grid of **both** your pictures and
  your live wallpapers (live ones are labeled "(live)"). Type to search, arrows to move, Enter to apply.
  Choosing one sets it and recolors the whole theme from it. Previews are made once and cached in
  `~/.cache/dwm-wall/thumbs`. The window uses your active theme's colors. Needs `rofi` (installed by
  `install.sh`); without it you get the old nsxiv/dmenu picker. `DWM_PICK_THEME=0` keeps the current theme
  when you choose, and `DWM_WALL_UI=nsxiv` (or `dmenu`) forces the simple picker.
- `Super+Ctrl+W`: random wallpaper
- Bottom bar: click the picture icon (right-click for random)
- The last wallpaper is restored at login. CLI: `dwm-wall set <file>`, `dwm-wall random`.

## Bars

- **Top (dwm):** icon tags (terminal, web, files, code, chat, music, video, games, settings),
  layout icon, a plain window title (only the active tag is highlighted), and on the right a
  running cat (it speeds up with CPU load), `online ✓` / `offline ✗`, volume, brightness,
  battery, clock. Prefer numbered tags? See the comment above `tags[]` in `config.h`.
  "Online" means NetworkManager reports a full connection.
- **Bottom (polybar):** CPU, RAM, disk, temperature, uptime, network speed (Wi-Fi), plus
  wallpaper and theme buttons. Resources show used out of total instead of percentages: CPU as busy
  threads out of all threads (`1.6/8`, from `dwm-cpu`), RAM as `4.2 GB/15.4 GB`, disk as `45 GB/229 GB`.

Both bars float in the default style: an 8 px margin from the screen edge, rounded corners, and
the same 8 px gap between the bars and the tiled windows, so windows never touch a bar.

### Dock (Super+P)

`Super+P` runs `dwm-dock`. With the dock off (default) it opens the regular menu (`dmenu_run`).
Turn the dock on with `dwm-bar set DOCK=1` (or Super+Shift+B → Dock) and Super+P toggles a real
dock on the desktop - a polybar bar of application icons (terminal, web, files, code, settings)
with a launcher button, macOS-style. Press Super+P again to hide it.

### Clicking the top bar

Click (Button1) an item in the top bar:

| Item | Opens |
| --- | --- |
| `wifi online / offline` | network manager (`nm-connection-editor`; falls back to `nmtui` in a terminal) |
| `bluetooth on / connected` | Blueman (`blueman-manager`; falls back to `bluetoothctl`) |
| volume / muted | `pavucontrol` |
| battery | performance profile menu: Performance, Balanced, Power Saver (`powerprofilesctl`) |

The cat, brightness and clock are not clickable. Middle-clicking the status text still opens a terminal.
The click mapping is written by `dwmstatus` to `~/.cache/dwmstatus.actions`; `patch-dwm.py` adds the
small `dwm.c` change that measures the clicked segment.

Icons need a Nerd Font; the installer gets `ttf-jetbrains-mono-nerd`.

## Bar styles

`Super+Shift+B` (or right-click the theme button on the bottom bar) opens a menu; `dwm-bar` in a terminal
does the same. Pick a preset or change single options, then choose "Apply": dwm rebuilds and restarts
(about a second, windows stay).

| Preset | Look |
| --- | --- |
| `default` | two floating bars (dwm on top, polybar at the bottom), rounded windows, 8 px gaps |
| `classic` | edge-to-edge bars, square windows |
| `floating` | roomier: 12 px gaps and corners |
| `minimal` | one floating bar on top, numbered tags, dot icons, no cat; CPU/RAM/disk move into it |
| `dock` | one floating bar at the bottom |
| `stacked` | both bars stacked at the bottom, compact |
| `compact` | small centered second bar, alternate icons |
| `plain` | text labels, numbered tags, square and flat |

Options (`dwm-bar set KEY=VALUE`, `dwm-bar status`, `dwm-bar help`): `LAYOUT` (two bars top/bottom/flipped/stacked,
or one bar top/bottom), `FLOAT`, `GAP`, `RADIUS` (rounded corners, 0 = square), `WIDTH` (second bar full or compact,
centered), `DENSITY`, `ICONS` (nerd, alt, dots, text), `TAGS` (your config, icons, alt icons, 1 2 3, I II III),
`CAT`, `RES`, `BAR_OPACITY`, `ANIMATIONS`. Your choice is kept in `~/.config/dwm-theme/bar.conf`;
`BAR_PRESET=minimal ./install.sh` picks a first style at install time.

Rounded corners come from picom, so they need it running (the session starts it). Floating bars work by
keeping the work area inside the side margin; `patch-dwm.py` also moves a systray patch along. If your
`dwm.c` differs too much from stock dwm the patch says so and leaves the bars edge to edge.

## Thunar

The installer adds icons (Papirus), thumbnails (`tumbler`), trash/USB support (`gvfs`),
and right-click archives (`thunar-archive-plugin`, `file-roller`). The look comes from the
generated `~/.config/gtk-3.0/{settings.ini,gtk.css}`, so it changes with your theme.
Existing files there are backed up once as `*.bak-dwm-theme`.

## Keys (Super = modifier)

`Super+Shift+/` shows the full list. The basics:

- `Super+Enter` terminal, `Super+P` launcher, `Super+W` Firefox, `Super+E` Thunar
- `Super+Shift+T` theme, `Super+Shift+W` wallpaper, `Super+Ctrl+W` random wallpaper
- `Super+Shift+S` region screenshot to clipboard, `Print` full screenshot to `~/Pictures`
- `Super+J/K` focus, `Super+H/L` resize master, `Super+Shift+C` close
- `Super+1-9` tags, `Super+Shift+1-9` move window to tag
- `Super+T/F/M` tiled/floating/monocle
- `Super+Shift+Q` quit dwm (asks first)

## Changing things

- Keys, fonts, layout: edit `~/dwm/config.h`, then `cd ~/dwm && make PREFIX=$HOME/.local clean install`
  and restart dwm. Copy the file back here to keep the repo current.
- Bottom bar contents: edit `~/.config/polybar/config.ini`, then `pkill polybar` and relaunch
  (or run `dwm-theme set $(dwm-theme current)`).

## Notes

- dwm is X11 only. Foot is Wayland-only, so the terminal is kitty (which also supports
  fastfetch images: `fastfetch --logo-type kitty-direct`).
- dwm now installs to `~/.local/bin` (no sudo needed for theme changes). An older copy in
  `/usr/local/bin` is simply no longer used.
- The bottom bar relies on `patch-dwm.sh`, which changes a line or two in `dwm.c`. If your dwm
  source differs from 6.5 the script says so instead of guessing.
- Terminal transparency comes from kitty's `background_opacity` (default 0.85, change it in
  `~/.config/kitty/kitty.conf` or run `KITTY_OPACITY=0.9 ./install.sh`) plus `picom`, which
  `start-dwm` launches using `~/.config/picom/picom.conf`.
- `install.sh` is a menu: Install, Update, Restart, Quit. Update runs `git pull --ff-only` and re-applies
  everything without touching your `config.h`; run it every day or so. Install and Update return to the menu.
- `install.sh` keeps an existing `~/dwm/config.h` (so your own patches survive). `FORCE_CONFIG=1 ./install.sh`
  replaces it with the repo copy after saving a backup. If `dwm-power-menu` is in this repo it is installed too.
- **Status clicks:** `patch-dwm.py` adds `ClkStatusSegment` to `dwm.c` and a `statusclick` binding to `config.h`.
  `dwmstatus` writes `~/.cache/dwmstatus.actions` (one action per status segment); if you build the bar text
  yourself, keep the three-space separators or clicks will land on the wrong item.
- **Performance profile:** battery clicks use `powerprofilesctl` from `power-profiles-daemon`. The installer
  installs it and enables the service. Without it the menu shows a notification instead of failing silently.
- **Gaps:** `patch-dwm.py` (run by `patch-dwm.sh`, so by `install.sh`) replaces `tile()` and `monocle()` with
  gap-aware versions and adds `static const int gappx = 8;` to `config.h` if missing. Change the number in
  `config.h` and run `dwm-theme set "$(dwm-theme current)"` to rebuild. It also draws the top-bar power button
  without the accent box and trims `powertext` to just the icon. Each file is backed up once as `*.bak-le-dwm`.
- **Power menu:** `dwm-power-menu` follows the active theme (colors and Nerd Font). The status bar shows Bluetooth
  (`off` / `on` / `connected`) from `bluetoothctl`. blueman's own tray icon cannot take theme colors. To hide it and keep
  the themed text icon, try disabling blueman's StatusIcon plugin (check the key first with
  `gsettings list-recursively org.blueman.general`, then
  `gsettings set org.blueman.general plugin-list "['!StatusIcon']"` and restart `blueman-applet`;
  undo with `gsettings reset org.blueman.general plugin-list`).
- **Animations:** with picom 12+ (Arch ships 13) the installer adds an `animations` block to `picom.conf`:
  windows pop in/out when opened and closed, and tiled windows glide to their new spots (the experimental
  `geometry-change` preset). Durations are 0.28s open, 0.22s close, 0.28s move; change the `duration` numbers
  (seconds) in `picom.conf` to make them faster or slower.
  Dragging or resizing a window with the mouse animates too, which can feel laggy: set `ANIMATIONS=0 ./install.sh`
  or delete the `animations = (...)` block and restart picom to turn it all off.
- **Empty-workspace animation:** switching to a workspace with no windows plays a ripple: a ring in your
  theme's accent color grows from the middle of the screen and fades out (`dwm-flash`, built by the installer
  from `dwm-flash.c`; dwm starts it from `view()` via `patch-dwm.py`). With picom it is translucent.
  Preview it with `dwm-flash 0 0 1366 740 '#88c0d0' 800`, or turn it off with
  `touch ~/.config/dwm-theme/no-flash` (delete the file to bring it back).
- **Translucent bars:** picom also makes the top bar (dwm) and bottom bar (polybar) see-through via
  `opacity-rule` in `picom.conf`. Default 75%; change with `BAR_OPACITY=70 ./install.sh`, or edit the
  numbers in `picom.conf` and restart picom. This fades the bar text slightly too.
- The network-speed module watches Wi-Fi. For Ethernet change `interface-type` in the polybar config.
- Tearing was not an issue on an Intel UHD (i3-N305) laptop. If you see it,
  run `picom --backend glx --vsync &` from `start-dwm`.

## Themes from your wallpaper

```
dwm-wall auto on                 # from now on, every wallpaper change recolors the whole setup
dwm-wall auto off
dwm-theme from-image ~/Pictures/wallpapers/x.jpg        # one-off, from an image
dwm-theme from-image --light ~/Pictures/wallpapers/x.jpg   # light version
dwm-theme from-image ~/Videos/live.mp4                  # from a video / live wallpaper
```

`dwm-palette` picks the dominant color of the picture for the backgrounds and the most vivid color for the
accent, and nudges every text color until it is readable. Red/green/yellow/blue/magenta/cyan keep their fixed
hues so terminal colors still mean what they should. The result is saved as the "Wallpaper (auto)" theme, which
also shows up in the theme picker. Needs `python-pillow` (and `ffmpeg` for videos); `install.sh` installs both.

- Changing the theme rebuilds and restarts dwm (about a second), so auto mode does that on every wallpaper
  change. If the new colors are identical to the current ones nothing is rebuilt.
- Logging in never re-themes: `dwm-wall restore` only puts the wallpaper back.
- **Live wallpapers:** see below. The theme is sampled once from five frames spread across the video, not
  continuously (continuous recoloring would rebuild dwm over and over).

## Live wallpapers

`dwm-live` runs a video behind your windows with `xwinwrap` + `mpv` (the same flags as the usual one-liner) and
remembers the choice. Put videos in `~/Videos/Live wallpapers`.

```
dwm-live pick                 # choose from that folder (dmenu)
dwm-live random
dwm-live set "$HOME/Videos/Live wallpapers/Minecraft.mp4"
dwm-live off                  # back to the picture wallpaper
dwm-live status
```

With `dwm-wall auto on`, each change also recolors the whole setup from the video. Choosing a picture with
`dwm-wall` turns the live wallpaper off, and `dwm-wall restore` (run at login) starts the last live one again, so
you do not need your own xwinwrap line in any startup script. Needs `mpv` (installed by `install.sh`) and
`xwinwrap` from the AUR (`yay -S xwinwrap-git`). Open the picker with `Super+Ctrl+Shift+W` (added to your existing `config.h` by `patch-dwm.sh`, which
`install.sh` runs) or by middle-clicking the picture in the bottom bar.
